Privacy Policy / Gizlilik Politikası

English

MINIVERSE PRIVACY Effective: 2026-10-12 Publisher: Rüstem volga Aytaç Contact: volgaaytac@icloud.com ON THIS DEVICE MiniVerse stores your display name, level, lifetime XP, personal bests, play counts, completion receipts, preferences and tutorial state on this device. Pending online submissions include session IDs and gameplay events needed to retry uploads. Android credentials are encrypted using an Android Keystore key. iOS credentials use the Keychain. The app does not upload local XP or preferences as a cloud backup. Clearing app data or reinstalling can remove local progress; a recovery code does not restore it. ONLINE PLAY When online features connect, the service creates or uses a guest identity. It receives the guest ID, display name, authentication requests, game/session IDs, challenge language, scores, timing and bounded input events required to validate scores. Word Snap sends the selected answer for each word. The service stores game results, personal bests, seasonal participation and moderation records. Display names, accepted best scores, ranks, ratings and leagues are visible to other players in leaderboards. Avoid putting private information in your display name. ACCOUNT RECOVERY Recovery codes are random credentials shown only when generated. The server stores a hash, not the plaintext code. Codes remain valid until rotated or revoked. Recovering an identity invalidates its previous login tokens. Never share your code. Copying a code places it on the system clipboard, which is outside MiniVerse storage. OPERATIONS AND SECURITY Your network IP reaches the API and its hosting/reverse proxy infrastructure. Production rate limits store keyed hashes of client IPs or account IDs with counters and expiry times. Logs record request paths, status, timing and selected user/session IDs for diagnosis and abuse prevention. The app avoids logging passwords, recovery codes or authentication tokens. Expired rate counters are periodically removed; diagnostic logs and backups require the publisher's documented retention policy. Gameplay evidence and moderation records remain stored until the operator handles a deletion or retention request. Sign out deletes this device's login credentials; it does not delete server records. NO ADVERTISING OR PURCHASES This version has no ads, advertising identifiers, analytics SDK, purchases, email login, contacts, location, microphone or camera feature. Operational logging and gameplay validation still collect the data described above. Hosting providers process service data for operation; the publisher identifies its providers, legal basis and retention periods in the public policy. YOUR REQUESTS Contact the publisher to request access, correction or deletion of server records. Use the online identity shown in Account to identify the records; do not email a recovery code. Public policy: https://dark353.github.io/MiniVerse-privacy/privacy.html Account/data deletion: https://dark353.github.io/MiniVerse-privacy/support.html#deletion DIAGNOSTICS AND HOSTING The API is hosted on the publisher-operated server. GitHub Pages hosts these public support pages; GitHub may process visitors’ IP addresses and browser request information under its own privacy statement (https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Unity Engine Diagnostics is enabled in the current project and may process diagnostics under Unity’s privacy policy (https://unity.com/legal/privacy-policy). This is separate from gameplay score validation. No advertising or tracking SDK is initialized by the game.
